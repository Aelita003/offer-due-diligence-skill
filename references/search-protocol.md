# 检索协议 (Search Protocol)

阶段 2「收集证据」必读。定义通用来源、按类型专属来源、风险专用来源与检索策略。

## 一、通用来源（所有类型必查）

| 维度 | 来源 | 用途 |
|---|---|---|
| 公司基本面 | 公司官网（关于我们/产品/新闻/招聘页） | 业务、产品线、官方口径、团队规模信号 |
| 新闻动态 | 百度新闻、搜狗新闻、Google（外企） | 近期战略、融资、人事、产品、负面 |
| 业务与薪酬 | 招聘网站 JD（BOSS 直聘、拉勾、猎聘） | 在招岗位反映业务方向与扩张；薪酬区间 |
| 口碑文化 | 看准网、脉脉、牛客、小红书 | 加班强度、管理风格、面试体验（标主观） |
| 团队规模 | 领英 | 中国区团队规模、核心人员背景、近期异动 |
| 工商与风险交叉 | **爱企查 (aiqicha.baidu.com)** | 基础工商 + 司法/经营风险 + 变更记录 + 股东，**全功能免费**，作主交叉源 |

## 二、按类型专属来源

详见 `company-type-adaptation.md` 的"专属来源"小节。要点：
- **上市公司**：巨潮/披露易/SEC 年报与公告、东方财富/雪球、十大股东。
- **初创·融资期**：IT 桔子/企名片/投资界、36 氪、产品官网与应用商店、创始人访谈。
- **外企中国区**：母公司英文年报/10-K、在华新闻、领英、商务部外资信息。

## 三、风险专用来源（必查，对应问题⑤）

| 来源 | 查什么 |
|---|---|
| 国家企业信用信息公示系统 (gsxt.gov.cn) | 经营异常、严重违法、年报公示 |
| **爱企查 (aiqicha.baidu.com)** | **免费全功能**：司法风险、经营风险、行政处罚、变更记录、股东、对外投资——企查查免费版深度数据缺失时的**主要补充源** |
| 天眼查 / 企查查 网页版 | 行政处罚、司法风险、被执行人、股东穿透、关联企业（免费版深度数据受限，见下方说明） |
| 中国裁判文书网 (wenshu.court.gov.cn) | 涉诉案件，尤其劳动争议、合同纠纷 |
| 执行信息公开网 (zxgk.court.gov.cn) | 是否被执行人、失信被执行 |
| 信用中国 | 行政处罚、严重失信主体 |

> 连接器说明（重要——分两层，且注意免费版限制）：
> - **若已连接**企查查(qcc-company)/天眼查(tyc-mcp)/启信慧眼(qixinhuiyan-mcp)等工商连接器：用其结构化查询工具取**基础工商信息**（注册资本、法定代表人、成立日期、经营范围、统一社会信用代码、基本股东），可信度可评"高"。
> - **免费版深度数据受限**：企查查/天眼查免费账户的司法案件、裁判文书、行政处罚、实际控制人、最终受益人、股权穿透（10 层）、关联方图谱、变更记录多需 VIP 才完整可见，免费版仅有限/部分数据。故**深度风险数据（司法/处罚/被执行/股东穿透/实控人）不得仅凭连接器，须以下方政府源为准**，连接器仅作便利补充与交叉印证。
> - **若未连接**：回退到**联网搜索上述公开网页**，优先政府公示类权威来源（gsxt、裁判文书网、信用中国）。私企内部数据查不到时标"未公开"，不编造。
> - **爱企查（必用免费补充源）**：百度旗下 aiqicha.baidu.com，全部功能永久免费，含司法/经营风险、行政处罚、变更记录、股东、对外投资。企查查/天眼查免费版看不到的深度数据，**必须主动去爱企查补齐**，再与政府源（gsxt/裁判文书网/执行信息网/信用中国）交叉印证后采信。
>
> 连接动作在 WorkBuddy 平台层完成（非 skill 内）：左侧【专家/连接器】→ 找到企查查/天眼查 → 点 + 号 → 登录账号授权（方式一，免 API Key，30 秒）；或用 MCP 配置 + API Key（方式二，进阶，需去 agent.qcc.com 等平台取 Key）。

## 四、检索策略

1. **消歧**：同名公司用"城市 + 公司名""股票代码 + 公司名""创始人 + 公司名"组合检索，确认锁定正确主体。
2. **时效**：优先近 12 个月信息；用搜索引擎时间过滤；旧信息标注日期并提示"可能已变化"。
3. **交叉印证**：关键事实（营收、融资、客户、裁员）至少 2 个独立来源；单一来源的降级为"待验证"。
4. **负面专项检索**（必做）：组合"公司名 + 裁员 / 欠薪 / 投诉 / 维权 / 暴雷 / 处罚 / 诉讼 / 跑路"。
5. **口碑专项检索**（必做）：组合"公司名 + 加班 / 996 / 大小周 / 怎么样 / 面试体验 / 离职"。
6. **反证检索**：对每条重大正向判断，主动搜反向关键词（如声称"客户增长"→搜"流失/退订/投诉"）。
7. **口径核对**：涉及数字时，比对原始出处（年报原文 > 媒体转述），防口径被改写。
8. **竞品检索**（对应问题③，必做）：组合"公司名 + 竞品 / 竞争对手 / 对标的公司"检索；按行业/赛道搜索知名竞品（如"AI 陪伴 竞品""跌倒检测 融资"）；在爱企查看"疑似关系/同行"；在 IT 桔子/36 氪按标签搜同类融资公司。无结果则写"未识别到明确竞争对手"。
9. **赛道检索**（对应问题①，必做）：组合"赛道名 + 市场规模 / 行业报告 / 增速 / 竞争格局"检索（如"AI 陪伴 市场规模""养老机器人 行业报告"）；关注**静态盘**（体量、增速、竞争烈度、天花板）与**动态位**（周期：上行/下行/平稳）。周期信号用"赛道名 + 融资热 / 裁员 / 收缩 / 扩产 / 景气 / 需求趋势"检索，观察头部公司扩张收缩与融资热度变化。无权威数据时按"未公开"标注。
10. **财务健康信号检索**（对应阶段 3 第 7 项检查）：组合"公司名 + 融资 / 融资额 / 轮次"查融资总额与最近轮次时间（估跑道）；"公司名 + 招聘 / 裁员 / 扩张"查员工数趋势与招聘方向。

## 五、来源质量速判

- 可直接采信：政府公示、交易所公告、年报原文、监管文件、公开采访。
- 需印证：主流财经媒体、行业报告、招聘页。
- 仅作线索：公关通稿、软文、自媒体推广、融资 PR、匿名社区帖。

拿不准某来源属哪类时，按低一档处理并标注。
